# SatvaRise 🌿

SatvaRise is a 30-second pause-based AI reflection tool designed to help users regain control over impulses by choosing options instead of typing during urge states.

## Project Structure
- client/ → Frontend (React) – owned by Sommay
- server/ → Backend (Node + Express + Hugging Face) – owned by Kritika

## Core Principle
User does not type during urge state. User only selects options.

## Collaboration Rules
- Do not commit directly to `main`
- Use feature branches
- Do not change API contracts without discussion

## Current Version
MVP v1 – Single pause flow
